# Knowledge Base

A personal repository of learning guides and reference materials for various projects.

## Projects

- **[cluster-api](cluster-api/)** — Comprehensive guides for Kubernetes Cluster API, built for contributors moving toward maintainership. Start with [cluster-api/learning-path.md](cluster-api/learning-path.md).

## Structure

Each project folder contains:
- `README.md` — overview and reading guide for that project
- Concept/reference guides as markdown files at the same level as README
- Hands-on milestones and learning paths where applicable

## How to Use

1. Pick a project folder
2. Read its `README.md` for context
3. Follow the learning path or jump to the relevant concept guide
